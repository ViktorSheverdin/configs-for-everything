# configs-for-everything

Start arch with btrfs and kde
Install default apps
Set up git

Connect to Wi-Fi:
`iwctl --passphrase <passphrase> station <interface> connect NetworkName`

Download and execute script:
`curl -O https://raw.githubusercontent.com/ViktorSheverdin/configs-for-everything/main/arch-btrfs-gnome-install.sh`

`chmod +x arch-btrfs-gnome-install.sh`  
`./arch-btrfs-gnome-install.sh`
